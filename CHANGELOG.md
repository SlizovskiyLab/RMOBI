# Changelog

All notable changes to the RMOBI project are documented in this file.

## [v1.0.2] – Manuscript Publication Version

- Separated the statistical analyses, manuscript figure-generation scripts, and associated results into a dedicated GitHub repository.
- The analysis code and results are now available in [RMOBI-Analysis](https://github.com/SlizovskiyLab/RMOBI-Analysis).
- Organized the main RMOBI repository to focus on the computational framework and interactive web platform.

## [v1.0.1] – Intermediate Version

- Added `CITATION.cff` to provide standardized citation metadata for the repository.

## [v1.0.0] – Initial Manuscript Submission

- Initial version of RMOBI submitted for manuscript peer review.
